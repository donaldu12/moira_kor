# 🌌 moira_kor
> 칠정사여성반 Moira의 메뉴 및 텍스트 일부 한글화, 기능 추가 패치 버전

이 프로젝트는 점성술 프로그램인 **칠정사여성반 Moira**의 메뉴와 텍스트 일부를 한글화하고, 한국에서 사용하기 편리하도록 약간의 기능을 추가한 패치 버전입니다.

---

## 🚀 사용 방법 (Installation & Usage)

1. [Moira 공식 사이트](https://sites.google.com/site/athomeprojects)에서 기본 Moira 프로그램을 먼저 다운로드하여 설치합니다.
2. Moira가 설치된 폴더로 이동합니다.
   * *기본 설치 경로:* `C:\Program Files (x86)\At Home Projects\Moira`
3. 본 저장소에서 다운로드한 아래 **3개의 파일**을 설치 폴더에 복사하여 덮어쓰기(Overwrite)합니다.
   * `cities_k.prop`
   * `moira.jar`
   * `moira_k.prop`
4. 이제 프로그램을 실행하시면 한글화된 버전을 사용할 수 있습니다.

### 💡 신살 부분 한자 버전 사용 팁
기본적으로 신살 부분이 한글로 번역되어 있습니다. 만약 **기존의 한자 버전**을 그대로 사용하고 싶으시다면 아래와 같이 설정해 주세요.
1. 설치 폴더에서 `moira_k.prop` 파일을 삭제합니다.
2. `moira_k2.prop` 파일의 이름을 `moira_k.prop`로 변경합니다.
